## 3. Problemas achados (para corrigir)

### V-1 — Grande Cofre vazio sem explicação (MÉDIO)
Com `.gv` vazio, o resultado volta sem nenhuma opção e sem aviso.
```python
# web/masmorras_worker.py, no ramo do cofre, logo depois de montar itens_cofre:
if not itens_cofre:
    raise ValueError(
        "O export do AMR não traz opções do Grande Cofre. O cofre só abre depois do reset "
        "semanal (terça): faça um novo export no addon do AMR depois de abrir o cofre."
    )
```

### V-2 — Embelezamento com nome errado é ignorado em silêncio (ALTO como proteção)
O simc só imprime `Trivial: Player X item 'y' unknown embellishment 'z', ignoring` e simula **sem
o efeito**. Hoje os 21 nomes estão certos, mas um nome novo/errado daria número errado sem aviso.
```python
# simc_runner.run_simc: depois de rodar, varrer a saída
PADROES_IGNORADO = ("unknown embellishment", "has no effect, ignoring", "unknown item bonus")
avisos = [l for l in stdout_text.splitlines() if any(p in l for p in PADROES_IGNORADO)]
if avisos:
    raise SimcFalhou("O simc ignorou parte do perfil: " + " | ".join(avisos[:3]))
```

### V-3 — Rótulo de upgrade confuso no item forjado (BAIXO)
Item "Mito 6/6 + Forja" (341) mostra `brasoes: 0, ate: "Mito 6/6 (334)"`. Para forjado, o texto
deve ser "já no máximo (forjado, 341)".
```python
# data/trilhas.py::custo_upgrade
if d.forja:
    return {"moeda": MOEDA[d.trilha], "brasoes": 0, "etapas": 0, "ate": f"{d.rotulo} ({d.ilvl}) — máximo"}
```

### V-4 — Builds sugerem catalisar sem limite de cargas (MÉDIO)
A build de raide sugeriu **5 peças catalisadas** de uma vez; o Catalisador tem cargas limitadas.
O `ContextoSpec.max_catalisados` existe mas o worker passa `None`. Adicionar
`RankingRequest.max_catalisados: int | None` (campo "Cargas do Catalisador disponíveis" na tela, com
ⓘ) e repassar a `contexto_com_catalisador(..., max_catalisados)`.

### V-5 — Embelezamentos medidos dentro do ruído com refino baixo (MÉDIO)
Com refino 300 a margem foi ~0,75% e os embelezamentos ficaram entre −0,5% e −1,3%: a ordem entre
eles não é confiável. A fase 2 do Craft deve usar pelo menos 3.000 iterações.
```python
# masmorras/craft.py, fase 2
it_emb = max(it_refino, 3_000)
leitura2 = simular(fase2, it_emb)
```

### V-6 — String do AMR: erro técnico quando o usuário cola o export do personagem (BAIXO)
Hoje: "Modelo invalido: esperado '.qN' na posicao 15." Trocar por: "Isso parece o export do
personagem. Cole a string de **Best in Bags** que o site do AMR gera (Best in Bags → exportar para o
addon)." Detecção: o export do personagem tem blocos `.s1`… antes do `.q`.

## 4. O que só o usuário pode fazer (instruções)
1. **Pawn:** no jogo, `/pawn` → Escala → Importar → colar a string da tela (ou a da §1) → conferir se
   aparecem setas verdes em itens melhores.
2. **AMR:** no site do AMR, gerar o Best in Bags e copiar a string para o addon; colar essa string
   no campo "String do AMR (Best in Bags)" da tela, clicar "Gerar" na build, copiar e importar no
   addon (`/amr` → Importar). Conferir se o setup `WSIM-<build>` aparece com os itens certos.
3. **Grande Cofre:** depois do reset de terça, abrir o cofre, fazer um novo export do AMR e rodar o
   modo Grande Cofre.
