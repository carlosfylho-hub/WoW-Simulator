## 1. Como Delve funciona como fonte de gear

| Item | Detalhe |
| :--- | :--- |
| **Moeda** | Fragmento de Alma Mítica (*Mythical Soul Fragment*) |
| **Track gerado** | **Mítico 2/6** — nível **321** |
| **Vendedor** | **Wah'du**, no Labirinto de Kindo'jan |
| **O que ele vende** | Joias, capas, armas e mãos secundárias |

> ⚠️ **Correção registrada:** o Fragmento de Alma Mítica gera **Mítico 2/6 (321)**, não Mítico 1/6 (318) como constava antes.

### Onde Delve se encaixa

Delve é a fonte mais **acessível** de peças para os slots que dependem de raide. Não substitui o BiS, mas resolve o slot enquanto o drop não vem.
