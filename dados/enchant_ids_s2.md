> **Documento Oficial de Resolução de `enchant_id`**  
> **Total de Mapeamentos:** 97  
> **Fonte:** Wago DB2 `SpellItemEnchantment` + Nether Wowhead Tooltip  

## Por que este documento existe?
No export do SimulationCraft (`# SimC Addon`), a linha de equipamento exporta o campo `enchant_id=XXXX`.  
Este ID **não é o ID do pergaminho do item** nem o Spell ID lançado, mas sim o identificador interno da tabela **DB2 SpellItemEnchantment** (específico para cada rank de qualidade).  
Este dicionário mapeia com precisão cirúrgica cada `enchant_id` para seu respectivo nome oficial em PT-BR, nome em inglês, tier de qualidade, item do pergaminho e feitiço.
